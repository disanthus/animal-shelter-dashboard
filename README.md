# cs340-dashboard
CRUD dashboard and database for snhu cs340

Q. How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?

My CRUD Python module was built separately from the dashboard code so that the database operations were handled independently from the user interface. This makes the code easier to understand and modify because changes to database operations did not require rewriting the dashboard code itself. By keeping these basic  CRUD operations independent, it made them easier to read, maintain, and also made them for the future. Because my CRUD Python module is so simple and already-tested, it can be implemented for other databases or applications by making small, necessary tweaks to the code.
